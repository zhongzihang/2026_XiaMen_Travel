# 国庆厦门游玩规划网站地图与内容改版设计

## 目标与已确认的需求

为 2026 年 9 月 30 日至 10 月 4 日、两人同行的厦门游玩规划提供一份适合手机展示、可分享给同伴的静态网站。保留用户已给出的每日安排与景点；附件地图仅作为视觉方向参考，不将图片里的字样视作行程指令。此次只改网站，不制作或更新 PDF。

改版重点：

- 地图结合实际地理方位与手绘插画；住宿和主要景点按核验过的地图坐标落点。
- 景点标记按日路线着色、编号；支持切换日期、点击地点查看实拍图与简短提示。
- 处理吴番婆沙茶面、叶氏麻糍等图片无法显示或图片与菜品不符的问题。
- 去程、登岛渡轮、返程信息分别并入 9 月 30 日、10 月 1 日、10 月 4 日的每日行程；删除独立交通章节及对应导航入口。

## 方案比较与选定方案

1. 高德在线地图瓦片叠加路线：地理底图接近地图应用，但需要联网、地图服务配置与密钥管理，公开的 GitHub Pages 上易受网络或配置影响。
2. 纯手绘海报图：视觉自由且容易装饰，但点位会重新变成手工估计，不满足本次对坐标的要求，也不利于点选查看。
3. 自包含、坐标驱动的 SVG 地图（选定）：用经核对的地图坐标投影点位，在 SVG 上绘制手绘化海岸、道路、绿地与地标装饰；不加载远程地图瓦片，不需要 API Key。厦门岛区域和鼓浪屿用主视图加局部放大框组织，以免点位挤在一起。

路线彩线表示游玩顺序，不表示经核验的步行道路或导航轨迹；东渡至三丘田单独用海上渡轮线表示。视觉遵循参考图的轻旅行插画、日路线颜色区分、明确站点编号和图例，不复用参考图内非本行程的地点或文字。

## 地图数据与定位

- 点位记录名称、纬度、经度、坐标来源 URL、地图标注对象（景区中心/入口/码头）及精度说明；优先使用高德地图检索到的实际入口或码头 POI，而非景区中心点。
- 坐标使用同一坐标系。高德地图坐标为 GCJ-02；底图投影和点位投影共用同一输入，不混用未经转换的其他坐标系。
- 酒店地址以“夏商·怡翔酒店（厦门中山路文灶地铁站店）”和湖滨中路 7 号为核对目标。若高德未收录同名 POI，则用该门牌附近经高德确认的地址点作为近似标注，并在数据说明中明确“约”字，不伪装成酒店精确入口坐标。

## 页面结构与每日交通

- 顶部章节导航仅保留景点地图、每日行程、美食图鉴和出门小抄；去除独立“出发与返程/交通卡片”章节与导航。
- 9 月 30 日日程内呈现深圳北出发、厦门站到达、前往文灶酒店及首晚安排；动车票原图继续可点开放大。
- 10 月 1 日日程内呈现 09:30 左右前往东渡、10:30 东渡客运码头开船、抵达三丘田及返岛建议；以用户给定船票为准，不擅自改动码头或时间。
- 10 月 4 日日程内呈现退房/寄存行李的建议、老城半日动线、回酒店取行李与前往厦门站、返程动车和票图。
- 其他日程主体不改变；厦大方案仍保留“成功入校/未入校”两种走法。

## 图片与美食卡片

- 图片 URL 统一解析：本地文件名、以 `assets/` 开头的相对路径和完整远程 URL 都只解析一次，避免生成 `assets/assets/...`。
- 吴番婆沙茶面使用现有本地沙茶面实拍素材；叶氏麻糍不再使用鼓浪屿街景图，替换成对应的麻糍菜品/门店实拍，并在摄影署名中标清来源与“菜式实拍/门店实拍”属性。已找到携程叶氏麻糍门店页菜式实拍候选图：[叶氏麻糍（携程）](https://gs.ctrip.com/html5/you/foods/fooddetail/120058/319760.html)。采用前需确认图像能正常加载；若能合法且稳定地随站点打包，则优先使用本地文件。
- 每张美食图片的替代方案必须与对应菜式相符。远程图载入失败时不得回退成街景、其他菜品或虚称门店实拍；用匹配的本地菜式参考图，或显示清楚的占位提示。
- 保留分类筛选、可点击卡片、详情弹层、店名/地址/菜式说明/两人点单建议，以及大图查看交互。

## 实现范围

预计修改 `index.html`、`app.js`、`styles.css`、`credits.html`，必要时添加自包含 SVG 底图或图片至 `assets/`，并同步更新 `README.md` 与网站源码 ZIP。保留纯静态 GitHub Pages 兼容，不增加运行时地图 API 密钥或构建步骤。不改动车票原图，不更新 PDF，不改变已经确定的船票时间与码头。

## 验收标准

1. 地图坐标按比例映射后，酒店、厦门站、东渡码头、鼓浪屿三丘田、南普陀、厦大、白城、沙坡尾、植物园、钟鼓索道、八市/中山路等位置关系与高德地图核验结果一致；鼓浪屿与厦门岛方向正确。
2. 地图能按日切换路线、显示编号与起终点；点击景点可看到匹配的实拍图、名称和说明；鼓浪屿、东渡间显示渡轮段；地图在桌面与窄屏手机上完整可读，不产生页面级横向溢出。
3. 交通/动车信息只出现在对应的每日行程中，独立交通章节和导航入口不存在，去程与返程票原图仍可放大查看。
4. 所有美食分类筛选有响应，卡片与详情弹层可用；吴番婆与叶氏麻糍显示对应菜品图，故意断开远程图后也不出现裂图或错配照片。
5. 执行 `node --check app.js`，通过本地网站在桌面和 390px 手机视口检查布局、路线交互、图片错误回退及每日交通内容；源码 ZIP 如更新则检查目录结构和本地素材齐全。

## 风险与范围说明

- 高德 POI 坐标可能指景区中心而非游客入口；因此代码数据须区分中心与入口，无法核实的点用近似标注。
- 景区营业、渡轮、交通、价格和供应可能在旅行日变化；本改版是游玩规划而非实时导航或运营承诺。
- 若酒店同名 Amap POI 不可验证，地图仍可完成近似落点，并在提示文字中披露精度。
- 当前目录不是 Git 仓库；因此无法在此目录提交设计说明。不会擅自初始化 Git。设计文件会留在站点目录供人工审阅；如后续需要提交，应在已连接的仓库副本中完成。

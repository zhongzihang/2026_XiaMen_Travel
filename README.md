# 2026国庆厦门游玩规划

这是可直接用于 GitHub Pages 的静态网站，不需要安装依赖或运行构建命令。请把 `index.html`、`styles.css`、`app.js` 和整个 `assets/` 文件夹一起上传到仓库根目录。

发布方式：在 GitHub 仓库的 **Settings → Pages** 中，将 **Build and deployment** 设为 **Deploy from a branch**，选择 `main` 分支和 `/ (root)`，保存后等待 Pages 地址生成。

网站包含两张动车票原图和出行日程。GitHub Pages 网站通常可被公开访问；发布前请确认你愿意公开这些信息。网站顶部的“打印 / 保存 PDF”可生成离线版本，建议打印选项中打开背景图形。

所有图片为用户提供的票据截图或实拍图片，摄影署名和许可见网站底部“摄影署名”。营业时间、天气、轮渡和索道运行情况以出行当日公告为准。
